This Section was inspired by Bingo Helper by Lilfroggy.

The implementation is made with some expansions I had in mind.

This was mainly designed for Bingo Usage, but should be usable for other purposes as well.
- I the original Developer (Hype_the_Time) have no interest in extending this for non Bingo usage.

When creating you own tutorial make sure to reuse the following selection ids to keep a standard. These allow for future automatic path
selection by the user for example if they have a preference to get a Dreadlord or going mage path etc.

Combat Preference
- Id: "mage" → for mage path.
    - like dreadlord etc
- Id: "melee" → for melee path.
    - like hyper cleaver, void sword etc
- Id: "Archer" → for archer path.
    - like dragon short bow.

Bingo Card Preference
- Id: "lowpt"
    - optimize for as low pt as possible. do everything automatic with minions where possible and do everything the fastest way only.
- Id: "speedrun"
    - Complete card as soon as possible. Means a lot of manual work.
- Id: "efficient"
    - Result that is long term the best result. This means optimization for overall such as implementing preperations for community goal
      within card time when having to wait, General pairing Community Goals with the Card such as Exterminator being done with Emans etc.

Carry Preference
- Id: "carry"
  - If you have friends that can carry
- Id: "nocarries"
  - If you do not have friends that can carry
